# Forever Tuned

Minor additions for World of Warcraft Forever.

## Features

-   Combined bag can be now moved and stays at that position
-   Opening any bag opens all the bags
-   Reagent bag is anchored to the combined bag
-   Show a class icon above target player's frame
-   Move level from the right to the left on nameplates
-   Move character screen buttons to the bottom
-   Make icons red when out of range

More to come…
